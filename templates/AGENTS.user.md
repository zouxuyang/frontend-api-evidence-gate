# 用户级 Codex 工作规范

## 基本原则

- 修改前读取项目 README、脚本、现有测试和局部 AGENTS.md。
- 先核实 API 和现有约定，再修改代码。
- 只报告实际执行过的验证。
- 保留无关改动，不擅自删除文件或绕过失败门禁。

## 前端与 API 验收

涉及页面、表单、表格、弹窗或抽屉时，必须优先使用真实浏览器验证关键用户流程。

至少验证：

- 页面可以打开；
- 按钮可以点击；
- 输入框可以输入；
- 输入内容进入实际请求；
- 请求 URL、方法、参数和 body 符合 API 约定；
- 弹窗或抽屉可以打开和关闭；
- 成功、失败和加载状态有反馈；
- 分页参数和页码切换正确；
- 空数据、长文本和窄屏布局可用。

完成后分别报告：修改内容、已执行验证、通过项、未执行项和阻塞。

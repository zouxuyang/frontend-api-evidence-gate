# 前端人工验收清单

## 页面与布局

- [ ] 页面标题、主要操作和返回入口清晰
- [ ] 主要按钮在桌面和窄屏下不异常换行
- [ ] label、输入框、错误提示关系清晰
- [ ] 表格只展示高价值字段
- [ ] 低频字段可在详情查看
- [ ] 长文本有截断、换行或详情入口
- [ ] 弹窗和抽屉没有超出视口

## 交互与反馈

- [ ] 点击按钮有明确反馈
- [ ] 保存期间按钮有 loading 或禁用状态
- [ ] 保存成功有提示并更新页面
- [ ] 保存失败保留用户输入并说明原因
- [ ] 弹窗和抽屉可以通过规定方式关闭
- [ ] 空数据、加载中和错误状态可理解

## 数据与接口

- [ ] 搜索条件进入请求
- [ ] 分页参数和总数正确
- [ ] 请求字段符合接口约定
- [ ] 状态值使用约定枚举
- [ ] 日期、金额和 ID 格式正确
- [ ] 列表没有为了展示而请求无关的大字段

## 证据

- [ ] Playwright 流程通过
- [ ] 关键请求已断言
- [ ] 失败场景已验证
- [ ] 窄屏或视觉检查已完成
- [ ] 未执行项目已明确说明

# 02 门禁分层

## L0：开发者本地快速检查

目标是几分钟内发现明显问题。

```bash
go test ./...
go vet ./...
pnpm lint
pnpm typecheck
pnpm test -- --run
```

## L1：Pull Request 必检

必须通过：

- Go 单元测试；
- Go 静态检查；
- Vue Lint；
- Vue 类型检查；
- Vue 构建；
- OpenAPI/schema 检查；
- 关键 Playwright 流程。

## L2：页面交互验收

涉及页面交互时必须覆盖：

- 页面打开和加载状态；
- 搜索和筛选；
- 表格空数据、单页、跨页和大数据量；
- 长文本和窄屏布局；
- 详情页、弹窗和抽屉；
- 输入、提交、成功、失败和重试；
- 实际请求体和响应处理。

## L3：发布前检查

根据系统风险增加：

- 真实测试数据库上的集成测试；
- 权限和数据范围测试；
- 数据库迁移检查；
- 视觉回归；
- axe 无障碍检查；
- 关键接口性能和重复请求检查。

## 失败处理

失败时必须保留：

- 失败命令；
- 失败步骤；
- 实际错误；
- 截图或 Playwright trace；
- 是否已修复；
- 剩余阻塞和责任人。

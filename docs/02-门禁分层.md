# 02 门禁分层

## L0：本地快速检查

目标是几分钟内发现明显问题。

```bash
pnpm lint
pnpm typecheck
pnpm test -- --run
pnpm build
```

## L1：Pull Request 必检

必须通过：

- 前端 lint、类型检查、组件测试和构建；
- API schema 或契约检查；
- 关键 Playwright 流程；
- 请求、响应和控制台错误断言。

## L2：页面交互验收

涉及页面交互时必须覆盖：

- 页面打开和加载状态；
- 搜索和筛选；
- 表格空数据、单页、跨页和大数据量；
- 长文本和窄屏布局；
- 详情页、弹窗和抽屉；
- 输入、提交、成功、失败和重试；
- 实际请求体和响应处理。

## L3：发布前检查

根据页面风险增加：

- 视觉回归；
- axe 无障碍检查；
- 关键 API 性能和重复请求检查；
- 权限、登录态和数据范围场景；
- 真实或接近真实的 API 集成环境验证。

## 失败处理

失败时必须保留：

- 失败命令；
- 失败步骤；
- 实际错误；
- 截图或 Playwright trace；
- 是否已修复；
- 剩余阻塞和责任人。

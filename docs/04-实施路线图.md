# 04 实施路线图

## 第一阶段：统一入口（1—2 天）

- 增加项目级 `AGENTS.md`；
- 增加 `Makefile` 的 `check`、`e2e-critical`、`verify`；
- 统一 CI 检查名称；
- 选一个最重要页面作为样板。

## 第二阶段：关键用户链路（3—5 天）

- 使用 Playwright 覆盖列表、搜索、分页、详情、编辑、保存；
- 增加请求体断言；
- 增加空数据、错误、长文本和窄屏场景；
- 将关键检查设置为 PR 必检。

## 第三阶段：API 契约（1—2 周）

- 维护 OpenAPI 或 JSON Schema；
- 生成或校验前端 API 类型；
- 检查接口变更；
- 禁止页面直接拼接未经类型约束的请求对象。

## 第四阶段：质量增强

- 加入视觉回归；
- 加入 axe；
- 加入 API 集成环境验证；
- 记录关键页面的验收覆盖率和失败原因。

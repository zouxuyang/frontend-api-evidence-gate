# 04 实施路线图

## 第一阶段：输入和输出协议（1—2 天）

- 固定 `acceptance-spec.yaml` 的页面、控件、交互、API、断言和质量字段；
- 固定 `acceptance-result.json` 的状态、结论、证据和请求响应字段；
- 增加输入与结果 schema 校验；
- 选一个列表、搜索、编辑流程作为样板。

## 第二阶段：确定性浏览器执行（3—5 天）

- 将结构化动作映射到 Playwright；
- 采集截图、trace、请求、响应和控制台；
- 增加空数据、错误、长文本、分页和窄屏场景；
- 对请求和响应执行 schema 断言。

## 第三阶段：指纹和增量重验（1 周）

- 建立页面、组件、API、schema、样式和数据快照依赖图；
- 计算规范化规格和运行环境指纹；
- 支持未变化场景复用，并输出 `reusedFrom`；
- 对全局组件和无法解析的依赖执行扩大重验。

## 第四阶段：模型复核和 Agent 协作（1—2 周）

- 将截图、规则检查和业务语义交给模型复核；
- 强制模型引用证据，不允许凭空判定；
- 输出后续 Agent 可直接消费的修复清单；
- 增加视觉回归、axe 和关键 API 性能检查。
